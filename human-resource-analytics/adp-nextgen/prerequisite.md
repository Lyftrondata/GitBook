# Prerequisite

### Setup Instructions

Follow the steps below to create an API Credentials for the [ADP Nextgen](https://www.lyftrondata.com/integration/human-resource-analytics/adp-nextgen/) driver setup with [Lyftrondata](https://www.lyftrondata.com)

#### Instruction: <a href="#instruction" id="instruction"></a>

To connect ADP to Lyftrondata, you need:

| ADP Next Gen Now account                | Admin privileges required                                                                                                                                                                                                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADP Client ID and Client Secret details | - Contact ADP client representative if not available. - These details are provided by ADP on request.                                                                                                                                                                                                                                 |
| Web Services certificate                | - File extension: .pem                                                                                                                                                                                                                                                                                                                |
| Private key                             | - File extension: .key - Format: PCKS12 or PKCS8EncodedKeySpec                                                                                                                                                                                                                                                                        |
| Application subscription                | - The ADP Client (subscribing organization) must purchase and subscribe to the application. - The subscription must be active for the consumer application to retrieve or post data from or to ADP.                                                                                                                                   |
| **TIP**                                 | **NOTE**: For instructions to obtain your Web Services certificate and private key, see ADP's [documentation](https://developers.adp.com/learn/how-to-articles/generate-a-certificate-signing-request#automated-process-steps-\(partner-process-steps\)). Ensure that you have proper authorization before creating the certificates. |
