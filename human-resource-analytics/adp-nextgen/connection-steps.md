# Connection Steps

### Establishing a connection

[Lyftrondata](https://www.lyftrondata.com) offers following methods connecting to  [ADP Nextgen](https://www.lyftrondata.com/integration/human-resource-analytics/adp-nextgen/). To establish your connection, use the connection strings described below.

### oAuth2

| Key                  | Value                     | Field    |
| -------------------- | ------------------------- | -------- |
| Client ID            | Your ADP Client ID        | Required |
| Client Secret        | Your ADP Client Secret    | Required |
| Perm Certificate Key | Your ADP Perm Certificate | Required |
| Cert Certificate Key | Your ADP Cert Certificate | Required |
