# Connection Steps

### Establishing a connection

[Lyftrondata](https://www.lyftrondata.com) offers following methods connecting to [Sage Employee Benefits](https://www.lyftrondata.com/integration/human-resource-analytics/sage-employee-benefits/). To establish your connection, use the connection strings described below.

#### OAuth2 <a href="#oauth2" id="oauth2"></a>

| Key           | Value                       | Field    |
| ------------- | --------------------------- | -------- |
| Client ID     | Your Sage API Client ID     | Required |
| Client Secret | Your Sage API Client Secret | Required |
