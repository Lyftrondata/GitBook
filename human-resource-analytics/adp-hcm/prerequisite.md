# Prerequisite

### Setup Instructions

Follow the steps below to create an API Credentials for the [ADP HCM](https://www.lyftrondata.com/integration/human-resource-analytics/adp-hcm/) driver setup with [Lyftrondata](https://www.lyftrondata.com)

### Instruction:

To connect ADP to Lyftrondata, you need:

| ADP Workforce Now account               | Admin privileges required                                                                                                                                                                                                                                                                                                             |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ADP Client ID and Client Secret details | <p>- Contact ADP client representative if not available.<br>- These details are provided by ADP on request.</p>                                                                                                                                                                                                                       |
| Web Services certificate                | - File extension: .pem                                                                                                                                                                                                                                                                                                                |
| Private key                             | <p>- File extension: .key<br>- Format: PCKS12 or PKCS8EncodedKeySpec</p>                                                                                                                                                                                                                                                              |
| Application subscription                | <p>- The ADP Client (subscribing organization) must purchase and subscribe to the application.<br>- The subscription must be active for the consumer application to retrieve or post data from or to ADP.</p>                                                                                                                         |
| **TIP**                                 | **NOTE**: For instructions to obtain your Web Services certificate and private key, see ADP's [documentation](https://developers.adp.com/learn/how-to-articles/generate-a-certificate-signing-request#automated-process-steps-\(partner-process-steps\)). Ensure that you have proper authorization before creating the certificates. |
