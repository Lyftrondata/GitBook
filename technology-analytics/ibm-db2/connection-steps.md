# Connection Steps

### Establishing a connection

[Lyftrondata](https://www.lyftrondata.com) offers following methods connecting to [IBM DB2](https://www.lyftrondata.com/integration/data-warehouse/ibm-db2/). To establish your connection, use the connection strings described below.

### Basic

| Key      | Value             | Field    |
| -------- | ----------------- | -------- |
| Hostname | Your DB2 Hostname | Required |
| Database | Your DB2 Database | Required |
| Port     | Your DB2 Port     | Required |
| Username | Your DB2 Username | Required |
| Password | Your DB2 Password | Required |

Follow the steps below to establish a basic connection
