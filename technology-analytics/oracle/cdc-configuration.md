# CDC Configuration

This guide outlines the steps required to set up Change Data Capture (CDC) using Debezium for an Oracle Database. CDC allows capturing and processing of data changes in real-time, which is useful for various applications such as data replication, synchronization, and event streaming.

### Prerequisites

* Terminal access to Oracle Database
* Basic knowledge of Oracle Database management

### Setup Steps

#### 1. Terminal Setup

```bash
cd /opt/oracle/oradata/
mkdir -p recovery_area
cd recovery_area
curl -O https://raw.githubusercontent.com/debezium/oracle-vagrant-box/master/setup-logminer.sh | sh
```

#### 2. Log Miner Setup

```bash
# Set Oracle SID
ORACLE_SID=XE
export ORACLE_SID

# Connect to Oracle DB using SQL*Plus
sqlplus /nolog <<- EOF
	CONNECT sys/oracle AS SYSDBA
	alter system set db_recovery_file_dest_size = 10G;
	alter system set db_recovery_file_dest = '/opt/oracle/oradata/recovery_area' scope=spfile;
	shutdown immediate
	startup mount
	alter database archivelog;
	alter database open;
    -- Confirm Database log mode is Archive Mode
	archive log list
	exit;
EOF
```

#### 3. Enable LogMiner Features

```bash
# Connect to Oracle DB using SQL*Plus
sqlplus sys/oracle@//localhost:1521/XE as sysdba <<- EOF
  ALTER DATABASE ADD SUPPLEMENTAL LOG DATA;
  ALTER PROFILE DEFAULT LIMIT FAILED_LOGIN_ATTEMPTS UNLIMITED;
  exit;
EOF
```

#### 4. Create CDC User/Schema

```bash
# Connect to Oracle DB using SQL*Plus
sqlplus sys/oracle@//localhost:1521/XE as sysdba <<- EOF
  CREATE USER C##Lyftrondata IDENTIFIED BY oracle DEFAULT TABLESPACE LOGMINER_TBS QUOTA UNLIMITED ON LOGMINER_TBS;

  GRANT unlimited tablespace TO C##Lyftrondata;
  GRANT CREATE SESSION TO C##Lyftrondata;
  GRANT SET CONTAINER TO C##Lyftrondata;
  GRANT SELECT ON V_$DATABASE TO C##Lyftrondata;
  GRANT FLASHBACK ANY TABLE TO C##Lyftrondata;
  GRANT SELECT ANY TABLE TO C##Lyftrondata;
  GRANT SELECT_CATALOG_ROLE TO C##Lyftrondata;
  GRANT EXECUTE_CATALOG_ROLE TO C##Lyftrondata;
  GRANT SELECT ANY TRANSACTION TO C##Lyftrondata;
  GRANT SELECT ANY DICTIONARY TO C##Lyftrondata;
  GRANT LOGMINING TO C##Lyftrondata;

  GRANT CREATE TABLE TO C##Lyftrondata;
  GRANT LOCK ANY TABLE TO C##Lyftrondata;
  GRANT CREATE SEQUENCE TO C##Lyftrondata;

  GRANT EXECUTE ON DBMS_LOGMNR TO C##Lyftrondata;
  GRANT EXECUTE ON DBMS_LOGMNR_D TO C##Lyftrondata;
  GRANT SELECT ON V_$LOGMNR_LOGS TO C##Lyftrondata;
  GRANT SELECT ON V_$LOGMNR_CONTENTS TO C##Lyftrondata;
  GRANT SELECT ON V_$LOGFILE TO C##Lyftrondata;
  GRANT SELECT ON V_$ARCHIVED_LOG TO C##Lyftrondata;
  GRANT SELECT ON V_$ARCHIVE_DEST_STATUS TO C##Lyftrondata;

  exit;
EOF

```

#### 5. Verify Archive Log Mode

```bash
-- Check Archive Log Mode via SQL Editor
SELECT LOG_MODE FROM V$DATABASE;
```

#### 6. Active Table CDC Setup

```bash
-- Create a table for CDC
CREATE TABLE "C##LYFTRONDATA".PRODUCTS (
  id NUMBER(4) GENERATED BY DEFAULT ON NULL AS IDENTITY (START WITH 101) NOT NULL PRIMARY KEY,
  name VARCHAR2(255) NOT NULL,
  description VARCHAR2(512),
  weight FLOAT
);

-- Grant necessary privileges
GRANT SELECT ON "C##LYFTRONDATA".PRODUCTS to C##LYFTRONDATA;
ALTER TABLE "C##LYFTRONDATA".PRODUCTS ADD SUPPLEMENTAL LOG DATA (ALL) COLUMNS;
```

### Troubleshooting

#### Issue: ORA-00257 Archiver Error

* **Cause:** Recovery files limit exceeded.
* **Solution:** Clean up old archive logs to free up space. Requires SYSDBA level access.



This document provides a comprehensive guide for setting up Change Data Capture (CDC) on Oracle Database. Make sure to follow the steps carefully and refer to the troubleshooting section if any issues arise.
