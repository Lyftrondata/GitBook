# Connection Steps

### Establishing a connection

[Lyftrondata](https://www.lyftrondata.com) offers following methods connecting to [Intersystems Cache](https://www.lyftrondata.com/integration/technology-analytics/intersystems-cache/). To establish your connection, use the connection strings described below.

### Basic

| Key      | Value                 | Field    |
| -------- | --------------------- | -------- |
| Hostname | Your CacheDB Hostname | Required |
| Username | Your CacheDB Username | Required |
| Password | Your CacheDB Password | Required |
| Database | Your CacheDB Database | Required |
| Port     | Your CacheDB Port     | Required |
