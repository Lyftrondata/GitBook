# Types of Destination

Lyftrondata supports two types of Destinations and offers a fully-managed Destination that you can directly start using for your pipelines:

#### Destinations

1. **Data Warehouse:** A data warehouse is a form of database that integrates copies of transactional data from disparate sources for analytical purposes. Examples of data warehouses supported by Lyftrondata include Amazon Redshift, Google BigQuery, Snowflake, and Firebolt. A data warehouse may hold several databases within it.
2. **Database:** A database is a collection of data organized for storage, accessibility, and retrieval. Though databases are not recommended as Destinations, Lyftrondata supports all the popular databases such as MySQL, PostgreSQL, CacheDB and Firebird.
